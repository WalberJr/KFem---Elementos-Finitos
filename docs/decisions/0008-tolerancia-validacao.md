# 0008 — Tolerâncias de validação contra o COMSOL

**Status:** Aceito (usuário, 2026-11-17)

**Decisão:** Diferença relativa ≤ 2% em grandezas integrais (ex.: corrente, carga,
concentração média na saída) e ≤ 5% em perfis ponto a ponto, comparando com resultados
exportados pelo usuário do COMSOL (CSV/TXT). Mesmas tolerâncias para comparar backends de
GPU com a CPU (Etapa 11).
